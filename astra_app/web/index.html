YOUR EVERYDAY APPS

Connect what you use.

Passwords and account verification stay in the account's own login flow.

W

WhatsApp

Owner self-chat PC tasks, isolated contacts, fixed away replies, and no reactions. Link from your phone’s Linked devices screen.

G

Google Workspace

Gmail, Drive, Calendar, Contacts, Tasks, Docs, Sheets, Slides and Forms. Use your own Desktop OAuth client.

A browser consent flow may take several minutes. API access is checked separately from saved authorization.

I

Instagram

Dedicated local browser profile and a bounded away watcher. The first scheduled tick checks readiness without sending.

After creating the watcher, restart the gateway to load its exact job ID. WhatsApp owner activity pauses both away channels; Instagram activity is not separately observed.

A

Android phone

Connect through ADB and approve your phone's USB-debugging prompt. Select the intended device before opening screen control.

Platform pauses

Restriction signals persist across restarts. Review the account and pause cause before explicitly resuming.

Notes & device sync

Create an Obsidian-friendly vault. Sync only your notes folder through Syncthing; connect your own devices with Tailscale.

Owner style learning

Collect a bounded, read-only sample before Astra started sending. It remains private; an owner-requested model analysis may transmit it to your provider.

Local calendar export

Create an .ics file to import into a calendar. This is separate from Google Calendar synchronization.

Services & recovery

Install user service templates for the dashboard and voice player. Create a private backup separately from the public release archive.

Backups contain account data. Keep them private and never add them to the source repository.
